# Table Tennis Booking — с подтверждением бронирования

Веб-система бронирования столов для настольного тенниса.

## Особенность этой версии

Это вариант системы с обязательным подтверждением бронирования.

Обычный пользователь выбирает стол, дату и время. Новая бронь получает статус `pending`.

Администратор или менеджер может:

- подтвердить бронь;
- отклонить бронь;
- отменить бронь;
- создать бронь сразу со статусом `confirmed`.

Администратор дополнительно управляет пользователями и ролями.

Отдельная версия проекта с полностью автоматическим бронированием без подтверждения будет храниться в другом репозитории.

## Возможности

- регистрация и авторизация;
- JWT access + refresh token;
- автоматическое обновление access token;
- роли user / manager / admin;
- расписание столов;
- бронирование по часовым слотам;
- защита от двойного бронирования;
- подтверждение и отклонение заявок;
- личный список бронирований;
- отмена своей брони не позднее установленного времени;
- адаптивный интерфейс для мобильных браузеров.

## Правила отмены

Обычный пользователь может удалить свою бронь, если до её начала осталось не меньше значения `BOOKING_CANCEL_HOURS`.

По умолчанию используется:

    BOOKING_CANCEL_HOURS=2

Если времени осталось меньше, пользователь связывается с менеджером или администратором вне сайта.

Менеджер или администратор может отменить бронь независимо от этого ограничения.

## Установка backend

Создать виртуальное окружение и установить зависимости:

    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt

Создать рабочий файл настроек:

    cp .env.example .env

После заполнения `.env` применить миграции:

    python manage.py migrate
    python manage.py check

## Сборка frontend

    cd frontend
    npm ci
    npm run build

Production-сборка создаётся в каталоге `frontend/dist/`.

## Безопасность

В Git намеренно не включаются:

- `.env`;
- реальные пароли и секретные ключи;
- access/refresh tokens;
- runtime-логи;
- Python virtual environment;
- `node_modules`;
- production `dist`;
- локальные backup-файлы `*.before-*`.
